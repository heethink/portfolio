# 개인 포트폴리오 웹사이트 (Portfolio)

깔끔하고 모던한 반응형 개인 포트폴리오 웹사이트입니다. 순수 HTML, CSS, JavaScript로 구현되어 있어 별도의 빌드 과정 없이 바로 브라우저에서 실행하거나 GitHub Pages로 무료 배포할 수 있습니다.

## ✨ 주요 기능
- 🌓 **다크 모드 / 라이트 모드**: 브라우저 테마 자동 감지 및 토글 기능 (localStorage 저장)
- 📱 **반응형 디자인**: 모바일, 태블릿, 데스크톱 완벽 지원 (햄버거 메뉴 포함)
- 🚀 **빠른 성능**: 외부 의존성(라이브러리) 없는 가벼운 Vanilla Web 구현
- 🎨 **세련된 UI**: Pretendard 폰트, 글래스모피즘 네비게이션, 세련된 애니메이션 및 카드 디자인
- 📬 **문의 폼**: 인터랙티브 메시지 전송 피드백 UI

## 📂 파일 구조
```
portfolio/
├── index.html       # 웹페이지 구조 및 콘텐츠
├── style.css        # 모던 디자인 및 반응형 스타일시트
├── script.js        # 다크모드, 모바일 메뉴, 폼 인터랙션
└── README.md        # 프로젝트 설명 및 배포 가이드
```

## 🌐 GitHub Pages로 배포하는 방법
1. GitHub에서 새로운 Public 저장소(Repository)를 생성합니다. (예: `my-portfolio`)
2. 이 프로젝트 폴더를 해당 저장소의 원격(remote)으로 연결하고 푸시합니다.
3. GitHub 저장소의 **Settings** > **Pages**로 이동합니다.
4. **Branch**를 `main`, 폴더를 `/ (root)`로 선택하고 **Save**를 누릅니다.
5. 1~2분 후 `https://<당신의GitHub아이디>.github.io/<저장소이름>/` 주소로 사이트가 배포됩니다.
